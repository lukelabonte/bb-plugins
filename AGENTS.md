# bb-plugins

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under the gitignored `docs/` tree (`docs/issues/<feature-slug>/`); nothing is tracked in git. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles are used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` plus `docs/adr/` (ADRs are local-only in this repo — `/docs` is gitignored). See `docs/agents/domain.md`.
